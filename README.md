# zhopi vpn

کلاینت VPN مخصوص **zhopi** با تم مشکی و قرمز، ساخته‌شده بر پایهٔ پروژهٔ متن‌باز `firefox-spider-vpn` (مجوز GPL-3.0).

> ⚠️ برنامه **غیررسمی** است و ربطی به Mozilla ندارد.

## ساخت
- ورک‌فلوی `.github/workflows/build.yml` همهٔ نسخه‌ها (اندروید، ویندوز، مک، لینوکس) را می‌سازد: از تب **Actions** گزینهٔ **Run workflow** را بزنید.
- فایل‌ها در **Releases** با نام `Zhopi-VPN-…` منتشر می‌شوند.
- نسخه (`version:` در `app/pubspec.yaml`) را برای نصب روی نسخهٔ قبل بالا ببرید.

## تغییرات نسبت به پروژهٔ اصلی
- نام و لوگوی جدید، تم مشکی و قرمز.
- شناسهٔ برنامهٔ اندروید `com.zhopi.vpn`.
- بررسی به‌روزرسانی از فید پروژهٔ اصلی خاموش است.

## مجوز
GPL-3.0؛ فایل `LICENSE` را نگه دارید و سورس را همراه برنامه در دسترس بگذارید. بیشتر کد از پروژهٔ اصلی است.

# zhopi vpn (English)
